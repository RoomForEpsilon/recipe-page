### What I learned

I'm getting better with css and with figma.  I'm beginning to see patterns in the designs and I'm getting more comfortable with my code organization.  There's still a ways for me to go though.

It was my first time designing for mobile, tablet, and desktop.  Once I got the mobile done, the tablet and desktop quickly followed as there wasn't a lot different.  Interestingly, I was able to catch some of my mistakes once I looked at the layout from the larget design sizes.
